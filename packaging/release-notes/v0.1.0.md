The first release of AgentTerm: a native Mac terminal for coding agents, with an iPhone remote. Protocol version 4.

## The Mac app

- **One click to an agent.** Claude Code, Codex, Antigravity and Copilot CLI, each in a real terminal session, in the project folder you pick.
- **Sessions that stay.** A small host holds them, so they keep running with the window closed. The app can stay in the menu bar.
- **Tabs.** Sessions, open files and diffs share one tab strip, with their agent's icon and the conversation's name.
- **Git.** The folder's changes with diffs; stage, unstage and commit.
- **Files.** Browse, create, rename and trash; edit text with syntax coloring; preview Markdown and Mermaid diagrams.
- **History.** Every conversation each agent had in a folder, to resume or to hand off to another agent with the conversation so far.
- **Usage.** Under each agent's terminal: the model, how full the context is, and what your account has left with reset times, for all four agents.

## The iPhone app

- Pair by scanning a one-time QR code on the Mac; each phone gets its own token, which the Mac can revoke. Several Macs can be paired.
- The same sessions in a terminal sized to the phone, with a key bar and a compose field for prompts.
- The folder's git changes, files and history, and starting an agent in any folder on the Mac.
