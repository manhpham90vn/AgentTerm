AgentTerm 0.4.0 speaks protocol version 6: update the Mac app and the iPhone app together. After updating the Mac app, restart the host when the app offers to; an older host does not know the new requests.

## New

- **Push and pull from the Git tab.** Above the changes, Pull and Push act on the branch that is checked out, with the number of commits waiting. A branch that is not on a remote yet shows Publish Branch, which says where it goes and follows it from then on. git never waits for a password here: a remote that would ask fails with git's message. A pull that conflicts is undone.
- **Commit messages written by an agent.** Write, next to Commit, asks an agent for the message of what is staged and puts it in the field for you to read and change. It never commits. Choose the agent, the model and the prompt (style, language) in Settings > Git on the Mac or under Commit Messages in the iPhone's menu. The default is the first agent installed; Claude Code uses Haiku.
- **Diffs in two panels.** A button in a diff's header shows the file as it was and as it is now side by side, with line numbers. Settings > Git sets which of the two a diff opens in.
- **The Mac at a glance.** Processor, memory, network speed, temperature, battery and uptime of the Mac, in a line under the launch buttons and, for the Mac you are connected to, at the top of the iPhone app.
- **Much more to scroll back through.** A terminal keeps 20,000 lines instead of 500, and a device that opens a session is sent the last 4 MB of its output instead of 512 KB, so the iPhone can read what happened before you looked.
- **SSH hosts.** An SSH menu lists the hosts of `~/.ssh/config` and opens one as a session. From the iPhone the session runs on the Mac, which is then the way to that host.
- **A message you have not sent is kept.** On the iPhone, what you wrote in the message field of a session and did not send is there again when you come back to the session, also after closing the app.
- **Keep awake, with options.** Turn off by itself after 1 to 8 hours, keep the display on too, and only while the Mac is plugged in. The switch is in the menu bar menu as well.

Everything above is on the Mac and on the iPhone, and the settings are shared between them: the temperature in Celsius or Fahrenheit, diffs in one panel or two, and the rest. The iPhone app now opens on the list of your Macs, and inside a Mac has three tabs, Sessions, History and Settings, in place of one long menu. Its Settings follow the order of the Mac's.

Settings > General now links to the project's page and to the source.

## Fixed

- A diff jumped back to its top whenever the file changed, which is all the time while an agent is editing it. It now stays where you scrolled to.
- On the iPhone, a session that reconnects is sent only what it missed instead of all its earlier output again, and a slow connection is no longer taken for a lost one.
- On the iPhone, a connection that was lost while a session was open is noticed within seconds and made again by itself, back in the same session. Before, the terminal could sit there dead until you went out and came back.
- A terminal that changes hands between the Mac and the iPhone goes back to the live screen instead of staying where it was scrolled to.
- Opening the app while an agent was already running, the first launch after an update for one, could show a broken terminal: the session's earlier output was replayed into a terminal of another width. It is now replayed at the session's own size.
