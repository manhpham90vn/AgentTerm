AgentTerm 0.2.0 changes the protocol to version 5. Update the Mac app and the iPhone app together: 0.2.x does not work with 0.1.x.

## New

- **Arrange tabs and sessions.** Drag them into order, pin the ones you keep, and put related ones in named, colored groups that fold away. On the Mac in the tab strip, on the iPhone in the list of sessions; the arrangement is the same on both.
- **Arrange folders.** Drag a folder onto another, or drop one in from the Finder to add it.
- **Hand off to another folder.** A handoff can continue in a repository inside the conversation's folder, in another listed folder, or in any folder you pick.
- **Permissions.** Settings > Permissions lists what agents may ask macOS for (Accessibility, Screen Recording, Automation, Full Disk Access, Microphone, Camera), whether each is allowed, and a button to allow it. Programs in a session are now asked instead of being refused silently.
- **A warning when the host belongs to another copy of the app**, with a button to replace it.
- **The disk image has a shortcut to Applications** to drag the app onto.
- **Install with Homebrew:** `brew tap manhpham90vn/tap`, `brew trust manhpham90vn/tap`, `brew install --cask agentterm`.

## Fixed

- Stray characters appeared in a program's input after reopening a session.
- A second key bar showed above the iPhone keyboard when the terminal was tapped.
- The terminal's last line sat right on the bottom edge.
- The usage band was too low for its two lines.
- The tab menu had five ways to close with similar names; there are four now, each with a different reach.
