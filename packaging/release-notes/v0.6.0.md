AgentTerm 0.6.0 speaks protocol version 7: both the Mac and the iPhone have to be 0.6, and so does the host. After updating the Mac app, restart the host when the app offers to, then update the iPhone app.

## New

- **What each agent is doing.** Claude Code, Codex, Copilot CLI and Antigravity say through their hooks whether they are working, waiting for permission or an answer, or done, and both apps show it on each session. Codex's hooks have to be trusted once, in Codex; until then, and for what an agent cannot say, the app says why and what to do.
- **Told on the iPhone.** While you use the Mac from the iPhone, a banner in the app and a notification just after you leave it say when an agent finished or needs you, and a notification takes your answer. Once the iPhone was used, the Mac counts as away until you use its app again. A Live Activity on the lock screen shows the agents at work while no one is at the Mac.
- **Agents open shells you see.** Through AgentTerm's MCP server, installed in all four agents for your user and removable in Settings, an agent opens a shell as a tab (an SSH session, a dev server), types in it and reads it while you watch, and you can type in it too. The shells agents open are shared between them. "Agents run their commands in shells you see", on by default, asks them to work there rather than out of sight.
- **Schedules.** Start an agent with a prompt at a time, every day, on some days, or when its usage limit starts over, in a folder you pick. A run skips permissions only after you accepted what that means. The Mac's Schedules and the iPhone's Settings > Schedules show the runs going on, what is scheduled, and the runs that are over.
- **A worktree for a session.** Start an agent in a git worktree of its own, so its work does not mix with the folder's; the side panel shows the changes and files of any worktree of the folder, and merges it, opens a pull request or throws it away.
- **A window of places on the Mac.** A bar at the left, as the iPhone has tabs: Sessions, History, Schedules and Settings (⌘,), which is no longer a window of its own. History lists every conversation and shows the one you pick in the middle, to resume or hand off; the side panel keeps the folder's.
- **Keep awake, more ways.** Until a time, with the display on too, only on power, or only while an agent is working.
- **A long session scrolls smoothly on the iPhone.** Its terminal is drawn on the GPU, and a long session opens with the screen and the lines just above it; scrolling up brings the earlier ones, a page at a time.
- **Large files open when asked.** A text file over 2 MB offers Open Anyway, up to 20 MB.

## Changed

- A session keeps the size of the iPhone that used it when the iPhone goes away, until you type or click in it on the Mac; coming back, the iPhone takes it again by itself, without Fit This Screen.
- Settings are the same on both apps, and the iPhone's Mac settings cannot be changed while the Mac is out of reach.
- Room around the terminal on both apps.

## Fixed

- Push and Pull failed when git's credential helper was a program outside the system's folders, the GitHub CLI from Homebrew for one.
- A part that stops (the host, a session's program, the status line relay) is reported on both apps and started again where it can be; the host is kept running by launchd.
- Large repositories are quick: listing the changes of a repository of 50,000 files takes a tenth of a second rather than half a second, and a folder's changes are read again only when its files change.
- Attaching to a long session no longer holds up every other session.
