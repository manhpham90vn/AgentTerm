AgentTerm 0.2.1 speaks the same protocol as 0.2.0 (version 5), so a Mac and an iPhone on any 0.2.x work together. Coming from 0.1.x, update both apps.

## New

- **A warning when the versions do not match.** The Mac says so when the host still running is from another version, with a button to restart it; the iPhone says which side to update.
- **The version is shown in the app.** On the Mac next to Settings and in Settings; on the iPhone under the list of sessions.
- **HTML in Markdown previews.** Images, links, line breaks and headings written as HTML are drawn, and pictures next to the file show at the width asked for.

## Fixed

- A tall picture opened scrolled part of the way down. It now opens whole on the Mac and at its top on the iPhone.
- The tab strip could be scrolled up and down. It scrolls sideways only.

## Install

- **Mac:** `brew tap manhpham90vn/tap`, `brew trust manhpham90vn/tap`, `brew install --cask agentterm`, or the disk image below.
- **iPhone:** TestFlight, https://testflight.apple.com/join/Ny2JKHUp
